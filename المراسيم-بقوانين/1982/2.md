مرسوم بقانون رقم ( 2 ) لسنة 1982

بشأن اعتماد ميزانية الكلية الجامعية للعلوم والآداب التربية

لسنتين الماليتين 1982 و 1983.

نحن عيسى بن سلمان آل خليفة أمير دولة البحرين

بعد الإطلاع الدستور,

وعلى الأمر الأميري رقم ( 4 ) لسنة 1975,

وعلى القانون رقم ( 1 ) لسنة 1975 بشأن تحديد السنة المالية وقواعد إعداد الميزانية والرقابة على تنفيذها,

وعلى المرسوم بقانون رقم ( 11 ) لسنة 1978 بشأن وتنظيم الكلية الجامعية للعلوم والآداب التربية المعدل بالمرسوم بقانون رقم ( 16 ) لسنة 1980,

وبناء على عرض وزير المالية والاقتصاد الوطني,

وبعد موافقة مجلس الوزراء,

رسمنا بالقانون بالآتي:

المادة الأولى

تقدر المصروفات في ميزانية الكلية الجامعية للعلوم والآداب والتربية للسنتين الماليتين 1982 و 1983 بمبلغ ( 000ر298ر7 ) دينار ( سبعة ملايين ومائتين وثمانية وتسعين ألف دينار ) يكون نصيب السنة المالية 1982 مبلغ ( 000ر444ر3 ) دينار ( ثلاث ملايين وأربعمائة وأربعين ألف دينار ) ويكون نصيب السنة المالية 1983 مبلغ ( 000ر854ر3 ) دينار ( ثلاثة ملايين وثمانمائة وأربعة وخمسين ألف دينار ) وذلك وفقاً للجدول المرافق هذا القانون.

المادة الثانية

على الوزراء ـ كل فيما يخصه ـ تنفيذ هذا القانون, ويعمل به من أول يناير سنة 1982 وينشر في الجريدة الرسمية.
