مرسوم بقانون رقم ( 8 ) لسنة 1986

في شأن تعديل تسميتين في قوة دفاع البحرين

نحن عيسى بن سلمان آل خليفة أمير دولة البحرين. بعد الأطلاع على الدستور، وعلى الأمر الأميرى رقم (4) لسنة 1975،

وعلى قانون خدمة الضباط في قوة دفاع البحرين الصادر بالمرسوم بقانون رقم ( 16 ) لسنة 1977، والمعدل بالمرسوم بقانون رقم ( 11 ) لسنة 1983، وعلى قانون خدمة الأفراد في قوة دفاع البحرين الصادر بالمرسوم بقانون رقم ( 23 ) لسنة 1979 والمعدل بالمرسوم بقانون رقم ( 12 ) لسنة 1983، وبناء على عرض وزير الدفاع، وبعد موافقة مجلس الوزراء،

رسمنا بالقانون الآتي :

المادة الأولى

تعدل التسميتان التاليتان في قوة دفاع البحرين – أينما وردتا – في قانون خدمة الضباط الصادر بالمرسوم بقانو رقم ( 16 ) لسنة1977 والمعدل بالمرسوم بقانون رقم ( 11 ) لسنة 1979 وبالمرسوم بقانون رقم ( 11 ) لسنة 1983، وفي قانون خدمة الأفراد في قوة دفاع البحرين الصادر بالمرسوم بقانون رقم ( 23 ) لسنة 1979 والمعدل بالمرسوم بقانون رقم ( 12 ) لسنة 1983 المشار إليهما، وفي أي قانون أو نظام أو قرار أو أمر.
