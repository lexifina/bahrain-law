مرسوم رقم (28) لسنة 1996

بإعادة تـنظيم وزارة شئون مجلس الوزراء والإعلام

نحن عيسى بن سلمان آل خليفة أمير دولة البحرين.

بعد الإطلاع على الدستور،

وعلى المرسوم الأميري رقم (12) لسنة 1995 بتـشكيل الوزارة،

وعلى المرسوم رقم (9) لسنة 1995 بإعادة تـنظيم وزارة الإعلام،

وبناءً على عرض وزير شئون مجلس الوزراء والإعلام،

وبعد موافقة مجلس الوزراء،

رسمنا بالآتي:

المادة الأولى

يعاد تـنظيم وزارة شئون مجلس الوزراء والإعلام بحيث تشمل الإدارات التالية:

أولا - شئون الإعلام:

أ ) 1- الإدارة العامة للصحافة والإعلام الخارجي.

2- إدارة التراخيص اللاسلكية والترددات والرقابة.

ويشرف وزير شئون مجلس الوزراء والإعلام على هاتين الإدارتين.

ب ) إدارة الشئون الإدارية والمالية.

وتـتـبع هذه الإدارة وكيل الوزارة للإعلام.

ج ) 1- إدارة التسويق والترويج السياحي.

2- إدارة المرافق السياحية.

3- مركز التدريب للسياحة والفندقة.

4- مركز الجسرة للحرف اليدوية.

وتـتبع وكيل الوزارة المساعد للسياحة.

د ) 1- إدارة الثـقافة والفنون.

2- إدارة المتاحف.

3- إدارة الآثار والتراث.

وتـتبع هذه الإدارات وكيل الوزارة المساعد للثـقافة والتراث الوطني.

هـ ) 1- إدارة العلاقات العامة والخدمات الإعلامية.

2- إدارة المطبوعات والنشر.

3- إدارة المطبعة الحكومية.

وتـتبع هذه الإدارات وكيل الوزارة المساعد للمطبوعات والنشر.

و ) الإدارة العامة للصحافة والإعلام الخارجي وتضم:

1- إدارة الشئون الصحفية ووكالات الأنباء.

2- إدارة الإعلام الخارجي.

وتـتبع هاتان الإدارتان المدير العام للصحافة والإعلام الخارجي.

ثانيا - شئون مجلس الوزراء:

أ ) الأمانة العامة لمجلس الوزراء.

وتـتبع الأمين العام لمجلس الوزراء.

ب) 1- إدارة شئون الجلسات واللجان.

2- إدارة المعلومات والحاسب الآلي.

وتـتبع هاتان الإدارتان مساعد الأمين العام لمجلس الوزراء.

ج ) 3- إدارة الشئون الإدارية والمالية.

4- إدارة الوثائق والسجلات.

وتـتبع هاتان الإدارتان مساعد الأمين العام لمجلس الوزراء للشئون الإدارية والمالية والخدمات.

ثالثا - دائرة الشئون القانونية:

1- إدارة الفتوى والتشريع.

2- إدارة الاتـفاقيات والمعاهدات.

3- إدارة القضايا.

وتـتبع هذه الإدارات المدير العام للشئون القانونية.

المادة الثانية

يلغى المرسوم رقم (9) لسنة 1995 بإعادة تـنظيم وزارة الإعلام.

المادة الثالثة

علي وزير شئون مجلس الوزراء والإعلام تـنفيذ هذا المرســوم، ويعمــل به من تاريخ نشره في الجريدة الرسمية.
